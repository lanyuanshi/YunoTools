# YunoTools

**当前版本：v1.2.34**

安装包下载：[release/YunoTools-v1.2.34.apk](release/YunoTools-v1.2.34.apk)

一个功能丰富的 Android 工具箱应用，基于原生 Kotlin + Android SDK 开发。当前版本修复设置页检查更新：不再只扫描分享页前端壳 HTML，而是后台读取 Cloudreve 分享信息与文件列表接口，准确识别更新目录中的 APK 版本。

## 功能列表

### 首页
- **短视频去水印** - 支持抖音/快手/小红书/B站等短视频解析去水印。
- **AI聊天** - 接入 OpenRouter，支持模型配置、本地历史记录与智能对话。
- **音乐播放器** - 支持本地音乐、在线音乐搜索、收藏、下载、歌词和系统媒体识别。
- **日常工具** - 集成全能计算器、每日一题、Base64、订阅管理、横屏时钟、手持弹幕等工具入口。

### 音乐播放器
- **本地音乐** - 读取手机音频库，也可手动添加 `audio/*` 文件播放。
- **在线音乐** - 使用公开搜索接口展示歌曲，支持播放、收藏和下载。
- **歌词动效** - 自绘卡拉 OK 歌词，音符从上方落下碰字，文字轻微下压回弹。
- **系统媒体识别** - 通过 `MediaSession`、媒体元数据和媒体样式通知暴露播放状态。
- **播放同步** - 播放器弹窗、底部导航、列表播放状态实时同步。

### 日常工具
- **全能计算器** - 整合标准、科学、程序员、单位换算、日期、房贷、个税、BMI、折扣、小费/AA。
- **每日一题** - 每天随机一道离谱无厘头题，支持选择答案、查看解析、复制题目和临时换题。
- **订阅管理** - 提供基础/进阶/VIP/备用订阅入口，支持一键复制订阅链接。
- **Base64 工具** - 支持常用文本编码与解码。
- **横屏时钟** - 全屏横屏显示当前时间。
- **手持弹幕** - 全屏滚动弹幕，支持自定义文字、颜色与速度。

### 图像处理
- **图像压缩** - 选择图片后调节质量滑块实时预览压缩效果，支持保存到相册。
- **二维码生成** - 生成高清二维码，支持前景/背景色、Logo、保存与分享。
- **九宫格切图** - 自动居中裁剪为正方形并切分为 3×3 九宫格，支持批量保存。
- **以图搜番** - 上传动漫截图识别番剧名称、集数、时间点与相似度。

### 媒体处理
- **音频分离** - 从视频中提取音频。
- **改视频 MD5** - 修改视频文件 MD5 值。
- **视频剪切** - 选择视频后拖动范围或用秒级按钮微调，支持生成并保存剪切后的视频。

### 个人中心
- **解析历史** - 查看过往解析记录，点击可直接回放结果。
- **自定义头像** - 支持 GIF / WebP / 视频动态头像。
- **设置** - 支持主题切换、模型配置和功能参数管理。

## 技术栈
- **语言**: Kotlin
- **UI**: XML Layout + Material Design 3 + 原生动态 View
- **网络**: Retrofit2 + OkHttp3
- **图片加载**: Glide
- **音视频播放**: AndroidX Media3 (ExoPlayer)
- **系统播放通知**: AndroidX MediaSession + NotificationCompat
- **二维码**: ZXing
- **主题引擎**: 自定义 ThemeApplier 全局动态换色
